## 二、为什么是"重音压缩"而不是"音高压平"

前一阶段试过四种手段，只有一种可用：

| 手段 | 结果 |
|---|---|
| 调 `noise_scale` | ❌ 起伏反而变大（4.67 → 5.10 半音） |
| PSOLA 变调重合成 | ❌ 实现陷阱（颗粒放回原位，等于没做），修正后仍不理想 |
| WSOLA 分块变调 | ❌ 块边界跳变，起伏 5.84 → 7.36 |
| WORLD 音高压平 | ⚠️ 能压平（5.08 → 0.65），但**掉高频**（重心 856→807 Hz），听感"变哑"，用户判定不如原版 |
| **幅度动态压缩** | ✅ 纯乘性处理，不重合成，不损失音色 |

**核心区别**：压音高必然经过声码器重建，重建就有损耗；压重音只是乘一条平滑增益曲线，信号本身不动。

## 三、实现要点（踩过的坑）

1. **静音帧必须排除**：压缩公式 `(ref/rms)^(1-beta)` 对静音帧会算出发散增益（实测峰值 90 dB），把底噪放大成嘶声。必须 `gain=1.0` 锁定静音帧。
2. **增益要限幅**：否则等效于极端扩展。±22 dB 是听感与安全性的折中。
3. **增益曲线要平滑**（45 ms），否则出现"抽吸感"（pumping）。
4. **限幅会盖过 beta**：当 clamp 较小时，beta 再小也不起作用（实测 beta 0.05/0.02/0 输出完全相同）。调档要先放开限幅。

## 四、后续可调项

- 若觉得"太压了"：`beta` 0.2–0.5、clamp 12–16 dB
- 若觉得"还不够平"：clamp 提高到 26–30 dB
- 音色替换：同系列 13 个音色任选，只需改模型目录，其余参数不变（音色包按需下载，默认只内置 bronya）
