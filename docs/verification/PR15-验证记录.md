- Markdown：标题、粗体、列表、链接、行内代码、围栏代码、任意双分片位置、2000 个中文句子、长无标点、URL、小数与英文缩写通过；代码和 URL 不进入声音。

- Followup：模拟时钟在第 7 秒准入、第 8 秒截止、第 10 秒消费事件；Final 仍提交一次。截止后开始被拒绝，取消/切会话使用的失效路径、旧实例、重复 Final、识别超时拒绝事件不提交。协调器另验证 Followup 代次在 ASR Final 中原样保留。

- 纯停止词：经过语音 Final/打断判定后，增量生产者作废，后续文字与 finish 不再启动声音；原有语音肯定、否定、含糊、超时/重复审批回归继续通过。

本轮仍未执行真实麦克风、实体扬声器、MiMo 账号、ONNX 音质及 GUI 人工操作验收。没有将假设备/Mock 结果算作真机声学验证。保持 PR15 草稿，不合并、不发布，不实施 PR16。

- 默认 CUDA Windows build、fmt、clippy 通过（保留既有警告）。库测试 485 通过、3 忽略，仍筛除 1 项本机已安装 Kokoro 导致前提不成立的缺失模型测试；Agent HTTP/SSE 集成 29 通过。

- 新增真实 Agent → worker 增量消费 → 回退 maybe_speak → 同一 SpeechRuntime 的 900 字回复测试：请求中确有工具定义，协议终结前播放帧为零，结束后 150 句完整合成各一次。不能据此宣称普通带工具请求可以提前播报。
- 原慢速 SSE oracle 继续验证先正文后工具调用不提前播放；已有无工具收尾的首句音频早于末批文本。最终播报正文另验证排除了工具决策临时文字。
- 原 32 项队列暂满测试改为验证背压不产生 Failed，等待容量后能恢复。新增 5000 句持续积压：已接收声音不停止，合成序列是严格连续前缀，无重复，未播字符数与剩余正文逐字计算一致，正常排空无失败。另覆盖交接尾队列后立即停止，不再合成剩余文字。
- 完整回复的超 256 KiB 输入有明确预算提示；历史 400 字预览不再影响产品长回复。已接受部分继续播放。
- Followup 截止前准入/截止后 Final、无关设置保存、主动停止及语音确认肯定/否定回归保留。

本轮未执行真实麦克风、实体扬声器、MiMo API、ONNX 音质及 Windows GUI 手动操作；Mock 和假设备只证明协议、队列和状态行为。预算降级会有明确的未播尾部，完整正文仍可在会话查看。PR15 保持草稿，不合并、不发布，不开展 PR16。
