# PR14：MiMo 主页面播报设置

## 范围与技术选择

沿用 Rust + Slint、现有 SpeechRuntime 和单输出 WASAPI 播放链路。仅参考同所有者 SeleVox 的主页面预设数据、标签规则及请求语义，不迁移 WPF、工作台、Auto Speak、VoiceDesign 或 VoiceClone。未增加运行时语言或项目 unsafe。

整体标签为有序列表，最多16项，每项最多64个 UTF-16 单元，拒绝重复、控制字符、格式控制及括号。唱歌及 sing/singing 别名与普通标签互斥；添加时切换模式，载入非法组合时报错。标签按选择顺序生成 `(温柔 清亮)`，每个独立请求都加在 assistant 正文前。自然语言说明原样保留，最多1000个 UTF-16 单元，独立放在 user 消息。语速为1时不增加指令，旧配置只有 mimoStyle 时保持原请求结构。

MiMo 语速0.5–2.0转为自然语言近似指导，不保证精确倍率；本地 ONNX 仍使用自身 localSpeed 参数。音量0–1在播放前乘到真实 PCM 样本上，默认1跳过乘法，正文不受影响。没有引入时间伸缩算法。

标准模型 mimo-v2.5-tts 的流式模式沿用 SSE / PCM16 / 24kHz；关闭流式会发送 stream=false、audio.format=wav，并读取 message.audio.data，验证并解码 PCM16 WAV 后交给同一播放器。其他模型可以保存，但尚无验证过的协议时拒绝合成并提示，避免错误声称通用流式兼容。将来增加模型须验证其响应格式后显式开放。

请求正文按3000 UTF-8字节预算扣除标签前缀后拆分；不改现有总播报长度限制。每个片段携带相同前缀，字幕仍显示正文。前缀占满预算时要求减少标签。

## 凭据与云端许可

新增 SecretStore ID `mimo-tts`，与对话端点凭据分离。优先独立 TTS Key；不存在时，仅在用户选择允许复用时读取官方 `mimo` ID。缺省允许复用以兼容既有配置，不枚举或使用同族端点、DeepSeek Key。清除独立 Key 不影响官方账号；若开启复用，清除后会回退到官方账号。Key 编辑与清除随设置的保存提交，取消不修改凭据。

检测/试听按钮使用已保存生效配置，草稿未保存时禁用；其行为是实际合成并播放，可能产生费用。不会启动自动检测。总播报启用开关与输入来源开关继续控制自动发送助手正文的许可。错误不展示不可信服务端原文，避免 Key 或音频 Base64 回显；HTTP状态仍有分类提示。

## 使用与保存

打开设置 → 语音输入/播报 → 选择 MiMo 云端。设置模型、流式、预置音色、标签、自然语言说明与语速；公共区设置音量和输出设备。浏览区可按名称或类别搜索48项预设，添加自定义标签，点击已选项移除或清空。折叠、搜索与刷新不落盘、不重建引擎。

设备为单输出：系统默认或 Windows 枚举出的名称。刷新可以重新枚举；已选设备丢失时沿用播放器的明确失败提示，刷新或改回系统默认后保存恢复。不增加混播和虚拟麦克风路由。同名设备仍按既有名称匹配，无法区分同名硬件。

新字段都有缺省值。取消/打开设置从保存配置回填，包括标签和多行说明。生效配置与未保存草稿分开显示；只比较当前有效后端的合成参数、设备、音量及有效凭据变化来决定重建，LLM设置或折叠操作不打断播报。本地模型路径、音色编号、推理设备与模型检查保留。

## 验证与边界

使用仓库 CUDA 默认构建环境 rust/target/pr13-cargo.ps1；未构建 CPU-only 版本。执行 Rust fmt、check、clippy、MiMo真实HTTP Mock、播报生命周期、设置保存及 Agent/PR12/多提供商相关回归。Mock覆盖标签和语速的位置、独立多句请求、非流式WAV解码、取消、断流及完成判定。新增保存重启与凭据隔离、实际 PCM 音量回归。

真实Windows GUI使用隔离 CUAVA_DATA_DIR，检查后端切换、MiMo面板、草稿标记、输入控件与设备刷新。隔离环境无MiMo Key：未验证云端音色、标签听感、近似速度效果或真实云端播放；未宣称Mock等同硬件验收。真实设备切换播放、拔出恢复、本地ONNX听感仍需硬件试听。

首次TTS单测中，历史 missing_model_message_is_actionable 因工作区已存在自动发现的Kokoro模型而失败；该项没有被本次修改，也不将它作为模型缺失环境验收。clippy现存Agent/Session参数数量及UiCommand大小等警告不在本次范围。

最终自动验证：库测试466通过、3忽略；另外1项历史模型缺失测试因工作区已有模型而显式排除。MiMo HTTP Mock 14通过；Agent 29通过、PR12工具30通过、模型发现1通过、设置凭据6通过，取消真实性测试通过。fmt/check/build/clippy完成，clippy保留既有警告。PCM音量0/0.5/1及独立TTS凭据保存/清除和配置重载测试通过。后续最终GUI重开遇到自动化坐标/截图缓存不稳定，未将该检查扩称为完整手动验收。
