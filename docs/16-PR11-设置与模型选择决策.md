# PR11：设置与模型选择体验

## 范围与取舍

保留 Rust + Slint 软件渲染、现有 Agent、Session 选择优先级和提供商协议。设置仍在工作线程构造完整候选配置，一次校验、一次保存；文字 Agent 不依赖本地模型存在。没有改动旧 Electron 数据或 PR10 构建与回退策略。

多行提示词采用显式配色的 TextInput + ScrollView，边框呈现焦点；光标移动更新滚动位置，换行原样进入配置。相比主题 TextEdit，这种方式沿用项目已有的中性配色，避免依赖默认调色板。打开设置时回填实际保存的提示词、采样参数和 TTS 草稿，取消后重开也从保存值恢复。

思考全文放入独立、有明确高度的滚动视口。折叠高度按同一字体两行文本的实际排版高度计算，滚到末尾；展开最多 320 逻辑像素。空白 reasoning 不产生气泡，思考始终不进入 TTS 正文。

## 模型目录、启用与默认

ProviderConfig.models 继续保存目录元数据；enabledModels 是独立的可选模型 ID 集合，model 继续表示默认模型且始终可选。旧配置缺少 enabledModels 时保留已有目录与默认模型；保存后显式记录集合。刷新目录不覆盖显式集合，取消启用不删除目录或缓存。新发现项可在设置中勾选。

缓存元数据仍按照端点与该提供商自己的 Key 恢复；账户不匹配时不恢复其目录元数据，但保留启用 ID。端点修改保留用户启用选择，并保存来源地址 modelsOriginUrl；设置标记“旧端点选择，未验证”。这不是可用性保证，用户可逐个测试或重新获取目录。默认、手填和目录项都可以保存，不按模型名字推断协议。

主输入区用 Slint PopupWindow 承载分组搜索与滚动，供应商名称来自配置，索引选择仍走既有 Session 请求配置路径。MiMo ThinkingLevel、DeepSeek ReasoningEffort 和显式声明的兼容协议沿用原实现；忙碌时禁用切换。Esc 和选择后将焦点送回主输入框。

## 草稿测试与本地模型

测试连接紧邻 API Key，未测、进行中、成功、失败分别显示文字状态。ProbeDraft 包含草稿版本，配合请求代数和字段相等检查拒绝迟到结果，包括改动后又改回的情况。测试不保存配置或 Key。

本地模型使用 rfd 的 Windows 原生文件/目录对话框，通过 Slint 的 winit 窗口句柄关联父窗口。文件对话框在独立线程运行，返回后只更新草稿并调用现有 KWS、Whisper 与 ONNX 路径检查。选择器使用成熟依赖，项目没有新增 unsafe。相比 PowerShell/WinForms 辅助进程，直接的原生对话框有明确窗口归属，不需要额外进程和脚本编码协议。检查结果仅表示文件布局或 Whisper 文件头通过，不冒充真实推理音质或 GPU 验收。

手动修改的非空模型路径在保存前重新验证；默认缺模型或原有缺模型不妨碍其它设置与文字功能。TTS 后端与音色统一在语音页编辑，本地路径也只有一处编辑，模型页提供摘要。

## 风险与后续扩展

在线目录不等于模型聊天可用，UI 始终标记未验证。原生文件对话框返回 None 时视为取消，底层操作系统错误仍可能表现为取消。当前只支持既有 KWS、Whisper、Kokoro ONNX 布局；不加入下载或 GPU 管理。未来若需要每模型独立协议能力，应增加显式元数据，不能猜测模型名称。

## 输入卡片交互修订

主输入区按用户补充参考调整为与主窗口一致的浅色圆角卡片：上方原生多行输入，底部依次为加号、既有权限、上下文用量、模型与档位、麦克风和发送。附件能力尚未实现，加号仅打开空弹层，不提供假功能。权限菜单使用原有四档及逐能力设置入口，快速选择先保存成功再更新权限运行态，忙碌回合禁止修改；不清除逐能力覆盖、暂停或临时授权。

模型菜单下方固定推理档位入口，在窗口右侧剩余空间足够时展开右侧关联面板，否则展开左侧面板，选项仍取当前真实协议。主入口只显示模型名与当前档位，目录搜索仍覆盖提供商。上下文圆环来自当前 Session 历史、系统提示词和既有工具定义的估算，使用当前模型实际上下文上限；回合结束用原 Agent 的统计刷新，点击可查看数量与模型方案来源。不是固定的装饰图标。

麦克风点击引入显式 Manual 聆听目的，复用已有直通 VAD/Whisper 路径，用户不需要说唤醒词；与语音确认/播报打断目的分开，确认请求优先级不变。点击打开的临时麦克风在一句识别结束后关闭；原已打开的唤醒监听保留。重复点击取消当前采集，过期结果仍经过原实例/回合归属检查；识别后沿用原语音指令提交行为。未新增模型格式或修改语音确认判定。Enter 发送、Shift+Enter 换行，组合输入尚未提交时不拦截 Enter。

## 权限颜色与提示词预设

标准、保守使用中性灰，宽松、免确认使用橙色；底栏、快捷菜单和设置页的选项保持一致。颜色只表示权限档位差异，不改变授权策略。

默认提示词替换为用户提供的小爱同学文本，工具规范之前的原文逐字节保留；工具规范经用户明确授权，按当前 Rust 版实际的 12 个工具校正，并说明未接入的文件/系统命令/联网工具。时效性信息无法联网时明确说明不能核实，不假装搜索。

原版提示词完整保留为“银狼”预设。采用既有 Option<String> 保存语义：None 是默认，银狼以原版全文保存，其它全文是自定义。没有增加第二份配置或覆盖已有自定义提示词；打开设置时根据已保存内容回填模式。选择预设仍需同一保存按钮提交。
