# PR17：录音收尾与模型错误呈现

## 决策

在主窗口和 HUD 增加“结束录音并识别”，保留“取消识别”。前者只收尾 Capturing 中的一句，后者丢弃。UI 保存开始一句时的实例号和句号，点击后发独立命令并清除令牌。worker 传给实例共享控制状态，音频线程核对回合、活动状态和溢出，再取已到达队列快照、冲出重采样余量、处理不足一帧 PCM、有声时长与尾音补白，复用 SessionMachine::finish。

不采用停止 VoiceHandle 的方案，因为停止会取消 ASR 和临时麦克风结果。自然端点和人工收尾只能取走一次 session；迟到请求不能操作下一句。Final/Rejected 沿用原目的、审批请求号和 Session 归属处理，临时麦克风恢复原偏好。没有新增 unsafe、依赖或通用控制框架。响应存在音频线程轮询与 worker 消息调度延迟。

## 错误边界

TurnOutcome 保留稳定 failure_reason，另加 failure_message。客户端仅提取 JSON code/message，隐藏实际认证 Key、可疑认证或请求内容、控制字符和超长字段。HTTP 状态来自实际响应；连接、超时、流错误不编造状态。无 JSON 错误字段时不展示任意正文。

状态和系统时间线使用同一份说明，HUD 复制主窗口状态，Session 通过原保存流程持久化。HTTP 200 SSE 错误结束请求，不执行其半截工具调用、不自动重试；用户取消仍走原有语义。网络库内部详情不持久化，避免 URL 等内容泄露。

## 使用与验证

录到有效语音且显示正在听时点“结束录音并识别”，等待正在识别及结果。丢弃请点“取消识别”。加载、未开始本句、转录期间不能提交。

新增测试覆盖不足一帧 PCM、有声时长、纯静音、重复收尾和旧回合请求；真实本机 HTTP/SSE Mock 覆盖 400/401/404/429/500 和 200 错误事件，经 LlmClient 与 Agent 检查错误分类、状态码和描述。硬件、GUI 与 Mock 验收分开记录。

## 输入区悬停交互

上下文圆环悬停显示统计与模型说明，移开关闭；推理档位入口悬停展开侧栏，保留点击选择、返回及 Esc，避免鼠标移向侧栏时提前关闭。模型列表的打开方式不变。
